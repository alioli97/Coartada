# Branding

App icon: an original house plan (paper, thick walls, three rooms) with a gold suspect token
and a gold magnifying glass, on the app's green (`#15803D`). Colors come from the app theme
(`lib/theme/app_theme.dart`): paper `#FDFBF7`, ink `#1A1A1A`, gold `#F59E0B` / `#B45309`.

The artwork is a Dart painter (`paintArt` in `tool/branding/render_icons_test.dart`), not an
SVG: there is no SVG renderer on this machine, and Flutter can render it directly.

| File | Use |
|---|---|
| `png/icon.png` | Full icon (iOS, legacy Android, web); art at 90% so the handle clears iOS corners |
| `png/icon_foreground.png` / `png/icon_background.png` | Android adaptive layers; art at 62% so it fits the safe circle (66dp of 108dp) |
| `png/icon_monochrome.png` | Android 13+ themed icon: outlines only (alpha) |
| `play_store_icon_512.png` | Google Play listing icon (512×512, no alpha) |

## Regenerating

1. Edit `paintArt` in `tool/branding/render_icons_test.dart`.
2. `flutter test tool/branding/render_icons_test.dart` (writes the 1024×1024 PNGs in `png/`).
3. `dart run flutter_launcher_icons` (config in `pubspec.yaml`).
4. Revert the unrelated `ios/Runner.xcodeproj/project.pbxproj` change the tool makes
   (`ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS`).
5. Rebuild `play_store_icon_512.png` from `png/icon.png` (resize to 512, drop alpha).

## Launch screen

Generated by `flutter_native_splash` (config in `pubspec.yaml`) from `png/icon_foreground.png`
on paper `#FDFBF7` (light) / `#0F172A` (dark); Android 12+ shows it on a green circle.
Regenerate with `dart run flutter_native_splash:create`, then revert its `ios/Runner/Info.plist`
reformatting.
