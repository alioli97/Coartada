# CLAUDE.md

## Project

Coartada (Dart package `coartada`, app id `com.alioli97.coartada`): an original logic-deduction game in Flutter. A house map is an N×N grid split into rooms, with furniture. The player places N people (one per row and per column, never on tables/plants/bookshelves) using clues, then names the culprit: the only person sharing the victim's room. Cases are **generated**, not hand-written, and always have exactly one solution. It is inspired by the "sudoku + murder mystery" genre but must stay original: never copy the name, cases, characters or art of existing games (e.g. Murdoku).

Work plan: `docs/ROADMAP.md`. Read it before starting a step and tick the step's box in the same commit that completes it. One step = one commit on its own branch, merged into `main` with CI green; commit messages in English, Conventional Commits.

Flutter 3.50 (Dart 3.14). Material widgets come from `package:material_ui/material_ui.dart` (never `package:flutter/material.dart`). No backend: everything is local (SharedPreferences).

## Architecture

- `lib/game/` — pure Dart, no widgets except `ChangeNotifier`:
  - `model.dart` — `Board` (size, variant, `roomOf`, `rooms`, `furniture`), `Clue` sealed hierarchy (`InRoom`, `NotInRoom`, `OnFurniture`, `NextTo`, `InRow`, `InColumn`, `InCorner`, `ByOuterWall`, `NorthOf`, `WestOf`, `SameRoom`, `DifferentRoom`, `SameDiagonal`, and `NobodyInRoom`, the one global clue: `appliesTo` every person, `isGlobal`, subject -1, shown with a door icon instead of a face). A new clue type needs: the class, a pool entry and weight per level in the generator, a sentence in all three languages in `Strings.clue`, `Puzzle`, `Level` (4×4…8×8: apprentice, detective, inspector, commissioner, legend), `Variant` (`classic`, `noTouch`), the `roster` of 8 names.
  - `solver.dart` — `countSolutions` (backtracking, stops at `limit`); encodes the rules, including "exactly one other person in the victim's room".
  - `generator.dart` — `generatePuzzle(level, seed, variant)`: random solution → rooms → victim/culprit → furniture → weighted clue pool → add clues until `Deducer.solvesAll` (which also proves uniqueness; `test/generator_test.dart` re-checks with the exhaustive solver) → remove clues while that still holds (keeps spares on easy levels). Deterministic per seed. The daily case is `Level.inspector` with seed `yyyymmdd`.
  - `tutorial.dart` — `tutorialPuzzle()`, the hand-made 4×4 guided case (Bruno → Darío → Abril → Carmen, each step teaching one idea; `test/tutorial_test.dart` pins that order). `GameScreen.tutorial` runs it with a coach card (two intro pages with Back/Skip, then `GameController.guide()` shows each deduction — free, pre-selecting the person — and points at mistakes); it is never saved or counted in stats and sets `AppState.tutorialDone`. Home shows a dismissible "First time?" card (`showTutorialCard`); How to play has a "Guided case" button when opened from home.
  - `deducer.dart` — human-style solver: candidate squares per person, ruled out by clues, taken rows/columns, "only one person can reach this row/column", a person whose every square clashes with another's, k people sharing k rows/columns, and the victim rule; simplest technique first, no guessing. `next()` gives the next forced placement with its `Reason`s and clue indices; `solvesAll()` checks a whole case. Every technique must stay sound (only rule out what the rules really forbid).
  - `game_controller.dart` — player state: placements, crosses, undo, hints (`hint()`: point at a misplaced person → explain the next deduction (`DeductionHint`, asking again places it) → reveal only if the deducer is stuck; `activeHint` drives the hint card and highlights), check → accuse → solved. Input modes (`InputMode`: place / cross / notes); pencil notes are `notes` (square → people), part of undo snapshots and of the save (`notes` is optional in `fromJson`, so older saves still load). Crossing a square out clears its notes. `toJson`/`fromJson` (versioned by `saveVersion`; bump it when the format **or the generator** changes, since a save only keeps the seed) store only the player's marks and time: the case is regenerated from seed + level + variant. The clock is `elapsed` (earlier sessions + a pausable stopwatch).
- `lib/core/strings.dart` — hand-rolled translations (es default, ca, en) via `_tr(es, ca, en)`, including clue sentences. Never hardcode user text in widgets.
- `lib/core/result_share.dart` — `resultShareText` (spoiler-free: case, level, variant, time, hints and the site link `shareLink`; never names, squares or the culprit) and `shareWithPlatform` (`share_plus`). `GameScreen` takes a `share` callback (default `shareWithPlatform`) so tests pass a fake; the case-closed dialog's Share button is disabled while the sheet is open.
- `lib/core/app_state.dart` — `AppState` (`ChangeNotifier`, passed through constructors): language, theme mode, no-touch variant, per level+variant stats (`LevelStats`: solved, best, and totals of time/hints over `tracked` solves — older entries only had solved/best, so averages use `tracked`), daily solved, daily streak (`daily_streak` {last, current, best}; only today's daily solved on its day extends it; it's broken once a whole day passes), game settings (`haptics`, `visualHelp`, both on by default), and one saved game (`saved_game`). `saveGame` doesn't notify (it runs on every move); the home screen calls `refresh()` after the game screen closes. `GameScreen` saves when progress changes (not on selection), when the app is hidden (clock paused) and on pop; an untouched new case never replaces the saved one, a resumed one always updates it.
- `lib/theme/app_theme.dart` — design tokens chosen with the UI UX Pro Max skill (`.claude/skills/ui-ux-pro-max`): light = "E-Ink / Paper" style, dark = "Card & Board Game" palette. Fonts are bundled in `assets/fonts/` (declared in pubspec, never downloaded at runtime): Playfair Display 700/800 for display/headline/titleLarge (`AppTheme.headingFont`), Source Serif 4 400/600 for everything else (`AppTheme.bodyFont`); OFL licenses registered by `lib/core/font_licenses.dart`. Using a new weight means adding its `.ttf` (verify its SHA-256) and a pubspec entry. Compact labels must stay on one line (`FittedBox` scaleDown), serif text is wider. Board colors live in the `GameColors` theme extension (`context.game`). Warm colors mean "you can stand here" (rugs, chairs); grey icons are obstacles.
- `lib/screens/` — `home_screen.dart`, `game_screen.dart` (rebuilds on the controller and on `AppState`; vibration goes through `_haptic`, which honours the setting; ⋮ menu opens settings too), `how_to_play_screen.dart`, `stats_screen.dart` (streak card + per-level stats per variant; opened from the home header), `archive_screen.dart` (daily cases of the last 30 days with solved / in progress / not played, opened from "Past cases" under the daily card; solved days are kept in `daily_done`, `dailyDone(day)` also reads the older single-value `daily_solved`). Dates are hand-rolled per language in `Strings` (`longDate`, `shortDate`; Catalan elides "d'" before a vowel); never ambiguous numeric dates. `lib/widgets/` — `board_view.dart` (CustomPainter for room tints, a faint floor pattern per `RoomKind` — tiles, planks, carpet dots, grass, stone — and walls, + tappable cells with `Semantics`), `furniture_glyph.dart` (hand-painted flat furniture: soft fill + 2px outline, no Material icons; rugs stay full size under people, chairs shrink to a corner badge), `suspect_avatar.dart` (original flat portraits painted per roster index — `_looks` — with the initial in white on a darker shirt, `shirtColor`; never below `minAvatarSize` 34dp so the initial stays ≥ 12px; excluded from semantics because the name is always beside it), `settings_sheet.dart`.

## UI rules (from UI UX Pro Max checklist)

- Touch targets ≥ 48dp. Board squares are ~48.7dp on a 7×7 board at 375px wide (18dp label strip, 8dp board gutter while other content keeps 16dp via `_gutter`); `test/board_size_test.dart` guards it for every level. Squares never go below `BoardView.minSquare` (48dp): when the board doesn't fit (8×8 on a phone) it becomes `_ZoomableBoard` — InteractiveViewer at 48dp squares, one-finger pan, pinch, and a "Whole board / Zoom in" button so zoom never needs two fingers. `GameColors.roomTints` must have at least as many tints as the biggest level has rooms (7).
- Text contrast ≥ 4.5:1 in both themes; check new colors in light **and** dark.
- Furniture ink (`blockedIcon`, `seat`) keeps ≥ 3:1 on every room tint, floor pattern and taken shade: `test/furniture_test.dart` checks it, so a new tint or ink must pass there.
- No emoji as icons; Material icons only. Never rely on color alone (rooms have thick walls + legend; people have initials).
- Motion: use the tokens in `Motion` (`lib/theme/app_theme.dart`) and always `Motion.of(context, d)`, which is zero under reduced motion (`MediaQuery.disableAnimations`). Transform/opacity only, never block input, and game state never waits on an animation. Current animations: suspect drop (`TweenAnimationBuilder` keyed by person@square), board shake on a wrong check (`_shake` in `game_screen.dart`), final reveal (`_RevealPainter` dims other rooms and outlines the crime scene; the case-closed dialog waits `reveal + revealHold`). `test/motion_test.dart` covers both modes.
